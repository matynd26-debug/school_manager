# 🎓 SCHOOL MANAGER

### Application web de gestion scolaire

## 📌 Présentation du projet

**School Manager** est une application web développée avec le framework Django et le langage Python. Elle a pour objectif de faciliter la gestion des activités administratives et pédagogiques d'un établissement scolaire.

L'application permet de centraliser les informations relatives aux élèves, aux enseignants et à l'organisation scolaire dans une plateforme accessible et structurée.

## 🎯 Objectifs du projet

- Simplifier la gestion des informations scolaires.
- Centraliser les données des élèves et des enseignants.
- Faciliter le suivi administratif.
- Améliorer l'organisation des activités scolaires.
- Mettre en pratique les compétences en développement web avec Django.

## ✨ Fonctionnalités

- **Gestion des élèves :** enregistrement et consultation des informations des élèves.
- **Gestion des enseignants :** organisation et gestion des informations des enseignants.
- **Gestion scolaire :** centralisation des données de l'établissement.
- **Interface web :** accès aux différentes fonctionnalités depuis une interface utilisateur.

*Les fonctionnalités présentées sont à adapter selon les modules réellement développés dans l'application.*

## ⚙️ Installation et exécution

### 1. Cloner le repository

```bash
git clone URL_DU_REPOSITORY
```

### 2. Accéder au dossier

```bash
cd school_manager
```

### 3. Créer un environnement virtuel

```bash
python -m venv .venv
```

### 4. Activer l'environnement virtuel sous Windows

```bash
.venv\Scripts\activate
```

### 5. Installer Django

```bash
pip install django
```

### 6. Effectuer les migrations

```bash
python manage.py migrate
```

### 7. Lancer le serveur

```bash
python manage.py runserver
```

L'application sera accessible à l'adresse :

http://127.0.0.1:8000/
